# 0007 — A PWA that caches assets, never data

**Status:** accepted

## Decision

Installable (manifest, maskable icons, standalone display, app shortcuts,
safe-area insets, bottom tab bar). The service worker precaches the offline
page and icons, and caches hashed `/_next/static/` assets cache-first. Pages,
Server Action responses and API responses are **never** cached.

## Consequences

Phones on a shared yard device keep no copy of sales or customer data after
sign-out. Offline _entry_ (queueing production or sales while disconnected) is
deliberately not built: it needs conflict handling for stock and money, and is
a separate decision if the plant's connectivity requires it.
